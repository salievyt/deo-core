# DEO CORE — Digital Product Studio

Сайт на Next.js / React / TypeScript и backend на Django / DRF с админкой Jazzmin. Фирменный цвет `#F08331`, оригинальный SVG-логотип и адаптивные интерфейсы, созданные кодом.

## Быстрый запуск

Фронтенд: Node.js 20.9+. Backend: Python 3.13 или 3.14.

```bash
npm install
npm run dev
```

http://localhost:3000 — автономный режим со скачиванием брифа.

Для полной версии запустите Django по инструкции [backend/README.md](backend/README.md), затем:

```bash
npm run dev:full
```

Фронтенд будет получать опубликованный контент из CMS и отправлять заявки в Django.

## Backend и админка

- http://localhost:8000/admin/ — Jazzmin, контент, контакты, заявки, приватные вложения.
- http://localhost:8000/api/docs/ — документация API.
- http://localhost:8000/api/site/ — контент главной.
- PostgreSQL для размещения, SQLite для локальной разработки.
- Настраиваемый CRM webhook с очередью и повторными попытками.
- Роли редакторов и менеджеров, черновики, русский и английский контент.

Подробности запуска, переменные окружения, модель доступа, API, Docker и ограничения: [backend/README.md](backend/README.md).

## Структура

- `src/app/` — главная, кейсы, журнал, 404, юридические страницы, sitemap и robots.
- `src/components/` — секции сайта, локальная/API-форма, блок партнёров, страницы контента.
- `src/lib/api.ts` — адрес API, типы и клиент; `useSiteContent.ts` — загрузка CMS.
- `src/lib/content.ts`, `src/lib/partners.ts` — исходный контент автономной версии.
- `backend/config/` — Django, Jazzmin, DRF, CORS, настройки окружения.
- `backend/studio/` — модели, API, админка, миграции, тесты, команды.
- `compose.yaml`, `deploy/nginx.conf` — Docker-конфигурация PostgreSQL, Redis, Django, Nginx и опционального CRM-воркера.

## Сборка и проверки

```bash
npm run typecheck
npm run build
npm run preview
```

Статическая сборка — `out/`. Для связанного фронтенда укажите `NEXT_PUBLIC_API_URL` **до** сборки: например, `/api` при общем домене или `https://api.example.com/api` при отдельном backend.

Без этой переменной форма ничего не отправляет и скачивает TXT-бриф. При подключении Django форма сохраняет заявку, UTM, referrer и вложение на сервере. Неуспешная отправка не показывает подтверждение; заполненный бриф можно скачать.

Фронтенд поддерживает RU/EN на главной; внутренние страницы пока на русском. Новые CMS-кейсы и статьи открываются через query-маршруты без пересборки. Статический HTML SEO и sitemap обновляются при сборке; для полностью динамического серверного SEO понадобится серверный режим Next.js.

## Контент и бренд

Проекты из исходного ТЗ представлены как явно отмеченные концепции. Реальные скриншоты и результаты можно добавить через Jazzmin и отключить отметку концепции. Команда, отзывы, вакансии и статистика доступны как модели/API; новые отдельные UI-секции для них пока не создавались. Выдуманных контактов, отзывов и достижений нет.

Оригинальный знак: `public/deocore-logo.svg`. Шрифт Inter включён в сборку; внешние шрифтовые сервисы не используются.

Блок партнёров — две встречные ленты, затемнение краёв, пауза и статичная сетка при `prefers-reduced-motion`. Сейчас оставлены места под логотипы. В CMS редактируйте «Партнёры»; в автономной версии — `src/lib/partners.ts` и файлы в `public/partners/`.
