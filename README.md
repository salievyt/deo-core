# DEO CORE — Digital Product Studio

Адаптивный фронтенд сайта на Next.js, React и TypeScript. Весь интерфейс и визуализации проектов написаны кодом. Backend, CRM, база данных и аналитика не используются.

## Запуск

Требуется Node.js 20.9+.

```bash
npm install
npm run dev
```

Открыть http://localhost:3000.

## Проверка и сборка

```bash
npm run typecheck
npm run build
```

Статическая сборка находится в `out/`. Её можно разместить на любом статическом хостинге. Для локального просмотра сборки: `npm run preview`.

## Структура

- `src/app/` — главная, кейсы, журнал, юридические страницы, 404, sitemap и robots.
- `src/components/Studio.tsx` — главная и локальная форма брифа.
- `src/components/ProjectVisual.tsx` — интерфейсы проектов, созданные с помощью HTML/CSS/SVG.
- `src/lib/content.ts` — редактируемые тексты, услуги, проекты, этапы и статьи.
- `src/app/globals.css` — стили и адаптация под мобильные устройства.

## Возможности

Переключение русского и английского на главной, фильтры проектов, отдельные страницы кейсов и статей, раскрывающиеся услуги и FAQ, переключение этапов работы, мобильное меню, модальное окно брифа, валидация и скачивание заполненного TXT-файла. Внутренние страницы сейчас на русском.

Форма ничего не отправляет. Данные существуют только в состоянии страницы до её закрытия. Для выбранного вложения в текстовый бриф записывается только название; содержимое файла не загружается.

## Контент перед публикацией

Проекты помечены как визуальные концепции: реальные скриншоты, подтверждённые результаты, сведения о команде, контакты и отзывы не были предоставлены. Поэтому выдуманные контакты, достижения и отзывы не добавлены. Юридические страницы описывают текущую фронтенд-версию. При подключении сервисов их нужно обновить.

Шрифт Inter Variable включён в сборку через @fontsource-variable/inter. Внешние сервисы шрифтов не используются.
